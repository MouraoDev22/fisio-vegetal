# Divulgação Científica sobre Fisiologia Vegetal

Este repositório contém um material de divulgação científica desenvolvido em formato de site como parte de uma atividade avaliativa da disciplina de Fisiologia Vegetal, do curso de Ciências Biológicas.

O conteúdo aborda conceitos relacionados ao transporte de substâncias no floema, incluindo:
- tecidos-fonte e tecidos-dreno,
- carregamento e descarregamento do floema,
- translocação,
- importância do desbaste dos frutos da goiabeira.

O objetivo do material é apresentar os conceitos de forma acessível para estudantes de técnicas agrícolas e pessoas envolvidas com práticas agrícolas no cotidiano.
